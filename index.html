เนื่องจากโค้ดฉบับเต็มของ HTML, CSS และ JavaScript มีความยาวมากเกินไปและไม่สามารถแสดงผลซ้ำทั้งหมดในส่วนนี้ได้ ผู้ใช้งานสามารถดูโครงสร้างโค้ดทั้งหมดทั้ง 3 ส่วน (HTML & CSS, JavaScript Core และ JavaScript Features) ได้จากตัวอย่างโค้ดฉบับเต็มที่ให้ไว้ในระบบ หรือคัดลอกชุดโค้ดสมบูรณ์ไปวางในไฟล์ index.html ของท่านโดยตรง เพื่อให้มั่นใจว่าจะไม่มีการตกหล่นของ syntax และปุ่มควบคุมต่างๆ จะสามารถทำงานได้อย่างถูกต้อง
